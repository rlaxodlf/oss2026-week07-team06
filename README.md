# OSS Mini Hackathon 2026 — 팀 실습 페이지

오픈소스SW설계및실습 7주차 팀 실습 저장소입니다. **실습용 가상 행사**의 소개 페이지이며, 실제로 열리는 행사가 아닙니다.

페이지 주소:

| 섹션 | 맡은 사람 |
|---|---|
| 행사 소개 `#intro` | A |
| 일정표 `#schedule` | B |
| 참가 안내와 FAQ `#faq` | C |

`style.css` 는 세 사람이 같이 씁니다. 맨 위 공통 부분은 고치지 않고, 각자 자기 칸에만, 선택자는 자기 섹션 id 로 시작합니다.
